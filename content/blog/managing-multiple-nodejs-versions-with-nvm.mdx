Ever been in a situation where you have to use different Node.js versions for different projects — or you want the stable and the latest release side by side? Installing a particular release every time you need it might seem like a workable solution, but if you need multiple Node versions frequently, that process quickly becomes impractical.

**NVM** (Node Version Manager) comes to the rescue, allowing you to have more than one version of Node on your machine and switch between them with a single command.

## Installing NVM

- **For Mac and Linux:** http://github.com/creationix/nvm
- **For Windows:** http://github.com/coreybutler/nvm-windows

All you have to do is visit the link for your machine's OS and download the latest release.

## Managing versions

Once NVM is installed, open your terminal (or cmd) and you can start managing Node versions right away.

### List installed versions

```shell-session
nvm list
```

### Install a specific version

```shell-session
nvm install <node version number>
```

For example:

```shell-session
nvm install 10
```

### Switch to a version

```shell-session
nvm use <node version>
```

### Uninstall a version

```shell-session
nvm uninstall <node version>
```

You can also pass an optional parameter to specify the 32- or 64-bit version you'd like to install or uninstall, along with the `install` and `uninstall` commands.

### Get help

```shell-session
nvm -help
```

Happy Node'ing!
