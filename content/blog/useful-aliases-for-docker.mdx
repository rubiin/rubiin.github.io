Docker has been around for a long time, and it's my most-used tool — whether for spinning up a web server or trying out a new one. If you're like me and use Docker in your day-to-day dev workflow, these aliases will save you a few keystrokes on common use cases. Set them up in your shell configuration file (like `.bashrc` or `.zshrc`).

## Inspecting containers and images

### Get the latest container ID

```bash
alias dl="docker ps -l -q"
```

### Get container process

```bash
alias dps="docker ps"
```

### Get process, including stopped containers

```bash
alias dpa="docker ps -a"
```

### Get images

```bash
alias di="docker images"
```

### Get container IP

```bash
alias dip="docker inspect --format '{{ .NetworkSettings.IPAddress }}'"
```

### Show all docker-related aliases

```bash
dalias() { alias | grep 'docker' | sed "s/^\([^=]*\)=\(.*\)/\1 => \2/" | sed "s/['|\']//g" | sort; }
```

## Running and interacting with containers

### Run a daemonized container

```bash
alias dkd="docker run -d -P"
```

### Run an interactive container

```bash
alias dki="docker run -i -t -P"
```

### Execute an interactive command in a container

```bash
alias dex="docker exec -i -t"
```

### Bash into a running container

```bash
alias dbash='docker exec -it $(docker ps -aqf "name=$1") bash'
```

## Cleanup

### Stop all containers

```bash
alias dstop='docker stop $(docker ps -a -q)'
```

### Remove all containers

```bash
alias drm='docker rm $(docker ps -a -q)'
```

### Stop and remove all containers

```bash
alias drmf='docker stop $(docker ps -a -q) && docker rm $(docker ps -a -q)'
```

### Remove all images

```bash
alias dri='docker rmi $(docker images -q)'
```

## Building

### Dockerfile build

```bash
alias dbu='docker build -t=$1 .'
```

## Conclusion

Using aliases for Docker commands can significantly streamline container management by reducing the need to repeatedly type out long or complex commands. Aliases allow developers to customize and simplify their workflows, enabling quicker execution of common tasks, such as building images, running containers, or managing Docker networks. By creating personalized shortcuts, developers can work more efficiently and avoid errors caused by mistyping lengthy commands.
