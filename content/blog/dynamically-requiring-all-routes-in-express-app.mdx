Routing in Express means mapping URLs to handler functions: `app.get()` for GET, `app.post()` for POST, `app.all()` for all methods, `app.use()` for middleware.

As your app grows, registering routes one-by-one in a single file gets tedious. In this post, we'll look at a small trick that requires every route file automatically.

## The problem with manual requires

Splitting routes into separate files keeps each route in its own file, which makes debugging easier: you know exactly where the problem is. But you have to require each file and pass it to `app.use`. That's simple with two or three routes, but in a larger app with a dozen or more route files, `app.js` fills up with require statements. And there's a real chance you'll forget to register one.

## Dynamic route loading

The fix is a few lines that automatically require every route in the `routes` folder:

```javascript
const fs = require("fs");

/**
 * Dynamic Routing
 * Adds all routes from the routes folder
 */
fs.readdir("./routes", (err, files) => {
  if (err) throw err;

  files.forEach((file) => {
    app.use("/", require("./routes/" + file));
  });
});
```

Here we use the filesystem module to read every file from the `routes` folder and register it on the Express `app` instance.

## Wrapping up

A few lines of code, and new route files are picked up automatically. For most projects, that's all you need.
