A quick reference for the Docker commands you'll use every day: building and running containers, managing them, working with images, and pushing to a registry. Bookmark it and come back whenever you need a reminder.

## Building and running

### Create an image using this directory's Dockerfile

```shell-session
docker build -t `<somename>`
```

### Run `<somename>` mapping port 8000

```shell-session
 docker run -p 8000:80 `<somename>`
```

### Same thing, but in detached mode

```shell-session
 docker run -d -p 8000:80 `<somename>`
```

### Run an image from a registry

```shell-session
 docker run username/repository:tag
```

## Managing containers

### Enter a running container (you can also use sh)

```shell-session
 docker exec -it [container-id] bash
```

### See a list of all running containers

```shell-session
 docker ps
```

### See a list of all containers, active and inactive

```shell-session
 docker ps -a

```

### Gracefully stop the specified container

```shell-session
 docker stop <hash>
```

### Force shutdown of the specified container

```shell-session
 docker kill <hash>
```

### Remove the specified container from this machine

```shell-session
 docker rm <hash>
```

### Remove all containers from this machine

```shell-session
docker rm $(docker ps -a -q)
```

## Working with images

### Show all images on this machine

```shell-session
docker images -a
```

### Remove the specified image from this machine

```shell-session
docker rmi <imagename>
```

### Remove all images from this machine

```shell-session
docker rmi $(docker images -q)
```

## Registry

### Log in to this CLI session using your Docker credentials

```shell-session
 docker login
```

### Tag `<image>` for upload to a registry

```shell-session
 docker tag `<image>` username/repository:tag
```

### Upload a tagged image to a registry

```shell-session
 docker push username/repository:tag
```
