The NestJS REPL (Read-Eval-Print Loop) lets you interact with a running NestJS application in real time. In this post, we'll look at what it can do and how to set it up.

## A quick primer on NestJS

If you're new to NestJS: it's a Node.js framework that uses TypeScript, a modular architecture, and decorators (inspired by Angular) for dependency injection. It works with Express or Fastify under the hood and supports everything from REST APIs to microservices to WebSocket apps.

## What the NestJS REPL gives you

The REPL gives you an interactive shell for debugging, testing, and inspecting your app's components without a deployment or server restart. Here's what it can do:

- **Access application context** and interact with services, controllers, and providers.
- **Inject and call services on the fly** without restarting the app.
- **Inspect variables and test functions live**, which is faster than adding console.log and restarting.
- **Run TypeScript snippets** directly, with full type checking.
- **Call methods on modules, controllers, and services** to test endpoints.
- **Load custom scripts** for application-specific utilities or database operations.

## Setting it up

To get started, create a new file `repl.ts`:

```ts
import { existsSync, mkdirSync } from "node:fs";
import { join } from "node:path";

import { Logger } from "@nestjs/common";
import { repl } from "@nestjs/core";

import { AppModule } from "./app.module";

const logger = new Logger("Repl");

async function bootstrap() {
  const replServer = await repl(AppModule);

  // OPTIONAL: sets up persistent history file for repl,
  const cacheDirectory = join("node_modules", ".cache");

  if (!existsSync(cacheDirectory)) mkdirSync(cacheDirectory);

  replServer.setupHistory(
    join(cacheDirectory, ".nestjs_repl_history"),
    (error) => {
      if (error) logger.error(error);
    },
  );
}
bootstrap();
```

Then you can run the app in REPL mode with:

```sh
npm run start -- --entryFile repl
```

Even better, add a script to your `package.json`:

```json
"start:repl":"npm run start -- --entryFile repl"
```

## Using the REPL

Once running, the REPL initiates an interactive server from which you can easily access your app's methods, either as:

```sh
get(AppService).getAllPosts()
```

or

```sh
$(AppService).getAllPosts()
```

You can also navigate through your command history with the ↕️ arrow keys.

Read more at the [official documentation](https://docs.nestjs.com/recipes/repl).
